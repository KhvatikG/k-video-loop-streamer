# VideoLoopStreamer - Автоматический видеоплейер для локальной сети

## 📌 Описание
Проект позволяет организовать непрерывное воспроизведение видео на Android TV/устройствах в локальной сети.
Приложение автоматически:
- Создает структуру папок при первом запуске
- Генерирует и обновляет плейлист
- Запускает DLNA-сервер для трансляции
- Отслеживает изменения в папке с видео

## 🚀 Особенности
✅ **Автоматизация**  
Нулевой ручной ввод после настройки. Просто добавьте файлы в папку `videos`.

🔄 **Реакция на изменения**  
Любые изменения в папке с видео (добавление/удаление/переименование) мгновенно обновляют плейлист.

📡 **Сетевая трансляция**  
Встроенный DLNA-сервер для воспроизведения на TV/смартфонах/планшетах.

## 📂 Структура проекта после запуска
```
VideoLoop/
├── VideoLoop.exe         # Исполняемый файл
├── videos/               # Папка для видео (автосоздание)
│   ├── promo1.mp4       # Пример видеофайла
│   └── promo2.mkv       # Поддерживаемые форматы: MP4/MKV/AVI/MOV
├── logs/                # Логи работы (автосоздание)
└── loop_playlist.m3u    # Автогенерируемый плейлист
```

## 🛠 Установка
1. Установите зависимости uv sync
2. Скомпилируйте проект, находясь в корне проекта:```uv run pyinstaller build.spec --clean```
3. Поместите exe-файл из директории dist в целевую директорию
4. При первом запуске автоматически создадутся:
    - Папка `videos` для ваших файлов
    - Папка `logs` для журналирования
    - Плейлист `loop_playlist.m3u`

## 🎬 Использование
1. Добавьте видеофайлы в папку `videos`
2. Запустите `VideoLoop.exe`
3. На Android TV:
    - Откройте VLC → **Сеть** → **Локальная сеть**
    - Выберите DLNA-сервер с именем вашего ПК

> ⚡ **Совет**: Для немедленного обновления плейлиста просто сохраните изменения в любом видеофайле.

## 🔧 Технические детали
- **Порт сервера**: 8080 (HTTP)
- **Форматы видео**: MP4, MKV, AVI, MOV
- **Системные требования**:
    - Windows 10/11
    - VLC 3.0+
    - 100 Мбит/с LAN/Wi-Fi
